# Spartan X (J) — ca65 disassembly

**English** | [Українська](README.uk.md)

A byte-exact, regenerable ca65/ld65 disassembly of **Spartan X (J) [!]** (Irem / Nintendo, Famicom; released abroad as *Kung Fu*).
The sources assemble into a ROM identical to the original dump, every routine, RAM variable and most constants have names,
and the whole `src/` tree can be regenerated from a few hand-edited label files.

| | |
|---|---|
| Mapper | 0 (NROM-256), vertical mirroring |
| PRG | 32 KB, CPU $8000-$FFFF |
| CHR | 8 KB (`gfx/`, `src/chr/`) |
| Vectors | NMI $82D8, RESET $8258, IRQ $FFF0 (points at sound data; no IRQ source is used) |
| Coverage | 0 unknown bytes: about 17.4 K code, 14.8 K data, 0.5 K pointer words (`docs/coverage.txt`) |

**The ROM is not included.** Put your own dump named `Spartan X (J) [!].nes` into the project root (it is git-ignored).
The expected size is 40976 bytes (16-byte iNES header + 32 KB PRG + 8 KB CHR).

## Requirements

- [cc65](https://cc65.github.io/) (`ca65` and `ld65` in `PATH`)
- Python 3
- optional: `make`; Mesen 2 in `mesen/` for the headless profiling scripts (not part of this repository)

## Build and check

```
python tools/disasm.py --build   # regenerate src/ from tools/labels/*.txt, assemble, compare -> IDENTICAL
python tools/lint_labels.py      # 0 problems
python tools/reloc_test.py       # 0 pointers that did not move
python tools/selftest.py         # OK
```

Other ways to do the same:

| Command | Does |
|---|---|
| `make` / `assemble.bat` | assemble `game.nes` from the existing `src/` |
| `make check` / `compare.bat` | assemble and compare with the original: `IDENTICAL` |
| `make test` | check + lint + relocation test + self-test |

## Editing

`src/` is **generated**. Names, classification and constants live in three hand-edited files (their formats are described
in each file's header):

- `tools/labels/rom.txt`: ROM labels, code/data/table/text/words classification, modules, notes
- `tools/labels/ram.txt`: RAM variables
- `tools/labels/const.txt`: named constants and operand substitutions (`NAME = value`, `use`, `data`)

After editing run `python tools/disasm.py --build`. If you edit `src/` by hand (for a hack), run the generator only with
`--out DIR`, otherwise it overwrites your changes. A patched build is no longer `IDENTICAL`.

## Repository layout

```
src/                  generated ca65 sources (src/prg/*.asm per module, src/chr/ CHR banks, *.inc)
tools/                generator, linter, relocation test, self-test, xref, CHR tool, metasprite and spawn-map tools
tools/labels/         rom.txt, ram.txt, const.txt: the hand-edited source of all names
tools/mesen/          headless Mesen 2 profiling bot (profile.lua, run_profile.py)
docs/                 documentation and generated reports (see below)
gfx/                  CHR pattern table sheets (generated by tools/chr_tool.py)
config.cfg            ld65 configuration (iNES header + 32 KB PRG + 8 KB CHR)
header.bin            16-byte iNES header, included by src/main.asm
Spartan X (J) [!].cdl Mesen code/data log used by the generator
game.mlb              labels for Mesen (generated)
Makefile, *.bat       build scripts
AGENTS.md, CLAUDE.md  working rules for AI assistants (CLAUDE.md just includes AGENTS.md)
```

Not in the repository (git-ignored): the ROM and every `*.nes`, build output (`*.o`, `game.map`, `game_labels.txt`),
the `mesen/` emulator, `reference/` (saved third-party pages), `skills/` and `TEMPLATE.md` (disassembly-project template
material), profiling output.
